## 공통 필수 설정

### 1. nodeSelector

```yaml
# upm-app 노드
nodeSelector:
  node-group.ntels.io/type: upm-app

# upm-ems 노드
nodeSelector:
  node-group.ntels.io/type: upm-ems
```

### 2. Node Eviction (빠른 축출)

노드 장애 시 빠른 Pod 재스케줄링을 위한 설정

```yaml
tolerations:
  - key: node.kubernetes.io/not-ready
    operator: Exists
    effect: NoExecute
    tolerationSeconds: 10
  - key: node.kubernetes.io/unreachable
    operator: Exists
    effect: NoExecute
    tolerationSeconds: 10
```

### 3. podAntiAffinity

```yaml
podAntiAffinity:
  enabled: true
  type: required  # required: 하드 제약 / preferred: 소프트 제약
```

### 4. topologySpreadConstraints (Skew)

labelSelector는 **instance Pod만** 선택하도록 지정 (pooler 등 사이드 리소스 제외)

```yaml
topologySpreadConstraints:
  - maxSkew: 1
    topologyKey: kubernetes.io/hostname
    whenUnsatisfiable: DoNotSchedule
    labelSelector:
      matchLabels:
        cnpg.io/cluster: upmdb-cluster
        cnpg.io/podRole: instance   # instance Pod만 카운트
```

> **주의**: `cnpg.io/cluster` 라벨만 쓰면 pooler Pod도 카운트되어 스케줄링 실패 발생

### 5. 롤링 업데이트 설정

```yaml
strategy:
  type: RollingUpdate
  rollingUpdate:
    maxUnavailable: 0
    maxSurge: 1
```
